# TraxLab — TraxKit harness app

The development host for TraxKit. It logs into mvServer (a real JWT via
MvAuth) and then hosts the kit the way a production host does: one
`TraxEngine` per signed-in identity, running app-wide (`LabSession`),
wiped on sign-out. It has a host-shaped tab bar that overlaps the hub's
sheet, and a Chats tab whose conversation reads the kit's bridge from its view
body, the way a chat host's thread header does.

The project is generated by XcodeGen from `project.yml`. Edit that file, then:

```bash
cd Demo && xcodegen generate
```

The generated `TraxLab.xcodeproj` is committed.

## Run

Develop against **Local** (mvServer on `:6170`, mvTrax on `:6091`, both in
local Docker); the login screen defaults to it.

```bash
open Demo/TraxLab.xcodeproj
```

### Debug dev sign-in

Debug builds skip the login when launched with `TRAX_DEV_TOKEN` (an HS256
token minted over the local stack's `TOKEN_KEY`, e.g. with mvTrax's
`cmd/minttoken`) and `TRAX_DEV_USER` (that account's UUID). It always talks to
Local. Two Lab-only options:

- `LAB_FRIEND=<uuid>`: the person the Chats tab's conversation is with.
- `LAB_START=chats`: open on the conversation instead of the map.

```bash
SIMCTL_CHILD_TRAX_DEV_TOKEN=$TOKEN SIMCTL_CHILD_TRAX_DEV_USER=$USER_ID \
  xcrun simctl launch <sim> dev.scalecode.TraxLab
```

## Tests

- Kit unit tests: `xcodebuild test -scheme TraxKit -destination 'platform=iOS Simulator,id=<sim>'`
  from the repository root (`swift test` can't build: the kit is iOS-only).
- Lab UI tests: `scripts/ui-test.sh <account-uuid> [friend-uuid]` mints a
  token and runs `TraxLabUITests` (signed-in hub loads; with a friend who
  shares, the conversation shows them). Screenshots land in `/tmp/traxlab-shots`.
- Live updates across two devices: `scripts/two-sim.sh <viewer-uuid> <sharer-uuid>`
  signs the sharer in on one simulator and drives it along a route with
  `simctl location`, parks the viewer on the conversation on another, and
  screenshots the viewer as the sharer moves. The coordinate and "Updated"
  lines must change between shots without the viewer leaving the screen.

Both scripts read `TOKEN_KEY` from the mvTrax checkout (`SERVER`, default
`../mvTrax`); see each script's header for its options.
